# Proyecto Expedición · Demo 0.2

## Qué contiene
- Avance frontal automático.
- Tres carriles.
- Ataque y esquiva.
- Tres enemigos normales y un jefe.
- Cofres con equipo que cambia el aspecto del personaje.
- Poder, vida y monedas persistentes mientras la página siga abierta.
- PWA instalable y funcionamiento offline tras la primera carga.

## Publicar en GitHub Pages
1. Crea un repositorio y sube todos los archivos a la raíz.
2. En Settings > Pages selecciona Deploy from branch.
3. Abre la URL en Safari desde el iPhone.
4. Pulsa Compartir > Añadir a pantalla de inicio.
